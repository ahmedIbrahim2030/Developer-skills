# Developer Skills & Editor Setup

This project is a small JavaScript learning exercise focused on core developer skills, debugging, and problem-solving techniques. It includes examples for working with JavaScript in strict mode, analyzing coding challenges, and fixing bugs through a structured debugging process.

## Overview

The project demonstrates:

- JavaScript fundamentals and strict mode
- Breaking down real-world coding problems into smaller steps
- Temperature amplitude logic and data filtering
- Debugging and fixing common logic issues
- Converting Celsius to Kelvin using a browser prompt

## Project Structure

- `index.html` — basic page layout and browser entry point
- `script.js` — JavaScript exercises, examples, and debugging demos
- `.vscode/` — editor configuration and local workspace settings

## How to Run

Because this is a static front-end project, you can open it directly in a browser:

1. Open `index.html` in your browser, or
2. Serve the folder locally with a simple web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- The JavaScript file contains several commented examples and mini-challenges for learning.
- Some code uses browser prompts, so it is intended to be run in a browser environment.
- This repo is mainly educational and meant for practice rather than production use.

## Learning Goals

This project helps reinforce:

- Writing clean, readable JavaScript
- Understanding algorithmic problem solving
- Identifying and fixing bugs efficiently
- Using the browser as a quick development environment
